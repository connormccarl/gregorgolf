This is a [Next.js](https://nextjs.org/) project.


## Project Info
**Client:** The Gregor Golf Club

**Company:** Key West Software

**Developer(s):** 1 only (Connor McCarl)

*Description:*

*This Next.js web application allows The Gregor Golf Club members to schedule and rent out Golf Simulator bays and get billed for it all through one platform. It also allows admins to manage the bookings, people, and account information while allows seeing some basic billing info.*
